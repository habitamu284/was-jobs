## 🚀 Quick Free Deployment (ያለ ምንም የGoogle ፍቃድ በነጻ ለማስኬድ)

### 1. Free 1-Click Hosting on Render.com (ነፃ እና ቋሚ ሰርቨር)
1. Go to [Render.com](https://render.com) and create a free account.
2. Click **New +** -> **Web Service**.
3. Upload this repository or connect your GitHub.
4. Settings:
   - **Environment:** Node
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
5. Click **Create Web Service**.
6. Within 2 minutes, Render gives you a public URL (e.g., `https://wasjobs.onrender.com`) that works on **all phones, Android, iPhone, and browsers without any Google permission or security prompt!**
